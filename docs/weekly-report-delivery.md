# Weekly Report Delivery

Weekly reports are generated by the `weekly-report` background job. Delivery supports local outbox files plus real SMTP or generic email API sending when credentials are configured.

## Current Providers

- `email`: sends through SMTP or a generic HTTP email API when configured.
- `local-outbox`: writes a local message-style file when `WEEKLY_REPORT_DELIVERY_OUTBOX_DIR` is configured.
- disabled: records delivery as disabled.

Email delivery can be planned as either:

- `smtp`
- `api`

This choice is stored in report metadata as `emailProvider`. Delivery metadata also records status, attempt count, recipient count, message id, and the final error message when all attempts fail.

## Environment

```bash
WEEKLY_REPORT_DELIVERY_ENABLED=false
WEEKLY_REPORT_DELIVERY_PROVIDER=email
WEEKLY_REPORT_EMAIL_PROVIDER=smtp
WEEKLY_REPORT_RECIPIENT_EMAILS=
WEEKLY_REPORT_EMAIL_FROM=
WEEKLY_REPORT_SMTP_HOST=
WEEKLY_REPORT_SMTP_PORT=
WEEKLY_REPORT_SMTP_SECURE=false
WEEKLY_REPORT_SMTP_USERNAME=
WEEKLY_REPORT_SMTP_PASSWORD=
WEEKLY_REPORT_API_ENDPOINT=
WEEKLY_REPORT_API_KEY=
WEEKLY_REPORT_DELIVERY_TIMEOUT_MS=10000
WEEKLY_REPORT_DELIVERY_MAX_ATTEMPTS=3
WEEKLY_REPORT_DELIVERY_OUTBOX_DIR=
```

Keep `WEEKLY_REPORT_DELIVERY_ENABLED=false` until provider credentials and hosted scheduling are ready. For SMTP, configure sender, host, port, username, and password. For API delivery, configure sender, endpoint, and API key. A report is only marked `READY_FOR_DELIVERY` when the selected provider has recipients and the required credentials.

## Hosted Schedule

The hosted scheduler plan includes the weekly report entry by default:

```bash
npm run jobs:schedule
```

The default weekly command is `npm run jobs:run -- weekly-report`, scheduled with `JOB_SCHEDULE_WEEKLY_REPORT_CRON_UTC=0 8 * * 1`. Keep `JOB_SCHEDULE_WEEKLY_REPORT_ENABLED=true` only in the one environment responsible for report generation.
